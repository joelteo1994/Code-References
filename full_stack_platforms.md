## Summary of key software platforms used in full-stack development 
Full stack data and AI team spans data ingestion and storage to model development and deployment 
1. Data Ingestion and Processing 
    - Apache Kafka: real-time data pipelines and event streaming 
    - Apache Airflow: workflow orchestration 
    - Fivetran / Stitch / Talend: ETL/ELT tools for ingesting data 

2. Databases and Storage 
    - MongoDB: noSQL database for unstructured or semi-structured data, based on documents 
    - PostgreSQL / MySQL: relational databases for structured data 
    - Amazon S3 / Google Cloud Storage / Azure Blob: Scalable cloud object storage
    - Snowflake / BigQuery / Databricks Delta Lake: Data lakes and cloud warehouses 

3. Data Engineering and Pipelines 
    - Apache Spark / Databricks: Big data processing and transformations
    - dbt (Data Build Tool): SQL-based data transformations and modelling 

4. Data Science & AI 
    - Jupyter / JupyterHub: Interactive Python notebooks for exploration
    - Python (Pandas, scikit-learn, NumPy): core language for data science 
    - PyTorch / TensorFlow: Deep learning frameworks 
    - Hugging Face Transformers: Pre-trained models for NLP 
    - MLflow/W&B (Weights & Biases): model tracking and lifecycle management 

5. APIs & Backend
    - Flask / FastAPI / Django: Python Frameworks for building APIs 
    - Node.js / Express: JavaScript backend frameworks 

6. Frontend & Visualisation 
    - React / Vue.js: interactive frontend frameworks
    - Dash / Streamlit / Plotly: Python-based data apps and dashboards 
    - Power BI / Tableau: enterprise-level BI visualisation tools 

7. DevOps & Deployment 
    - Docker / Kubernetes: Containerisation and Orchestration 
    - GitHub Actions / Jenkins / Gitlab CI/CD: Automated pipelines 
    - AWS / Azure / GCP: Cloud platforms for deployment 

8. Monitoring and Logging 
    - Prometheus / Grafana: Monitoring metrics and dashboards 
    - Sentry / Datadog: Error tracking and performance monitoring 
    - ELK Stack: log management
